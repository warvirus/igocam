igocam Architecture

가상 IP 카메라 서버 — ONVIF / RTSP / WebRTC / Web UI / MJPEG / PTZ · Go + OpenCV + ffmpeg + go2rtc 1.9.14

데이터 파이프라인

  • • frame.Frame 참조 카운팅 (NewFrame refs=1 → Retain/Release)
  • • 큐: drop-oldest, 닫힌 큐 Put 시 OnDrop → Mat 누수 방지
  • • 팬아웃: Streamer(ffmpeg) + MJPEG + Recorder 3방향
  • • 페이싱: paceFrame 단일 담당, 소스 FPS 자동 반영 (59.94→60)
  • • Streamer writeLoop: Mat Clone 후 write (race 방지) + 재접속

Bypass 모드 (파일/RTSP 전용)

  • • go2rtc가 소스를 직접 읽어 트랜스코딩 없이 전송
  • • #input=loop → -stream_loop -1 무한 반복 (파일 끝 사망 방지)
  • • 비-H264(AV1 등) → #video=h264 libx264 재인코딩
  • • IdleBypass: 로컬 소비자 없으면 캡처 1fps + 파이프라인 생략
  • • 카메라 디바이스/업로드 모드는 일반 인코딩으로 자동 전환

포트 구성 (카메라별)

  • • onvif_port: ONVIF SOAP + Web UI + MJPEG + 스냅샷 + 업로드
  • • rtsp_port / rtmp_port / webrtc_port / go2rtc_api_port
  • • 관리 서버 :8080 (공유 1개) — CRUD/제어/리로드
  • • 포트 자동 제안: FindAvailablePorts (+10 단위)
  • • go2rtc yaml: 카메라마다 data/go2rtc_{name}.yaml
